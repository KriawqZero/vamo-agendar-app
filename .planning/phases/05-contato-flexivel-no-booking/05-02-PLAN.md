# Plan 05-02 — Template React Email `ConfirmacaoAgendamento` e Suíte de Renderização

## Objective

Criar o template React Email `ConfirmacaoAgendamento.tsx` utilizando `LayoutBase.tsx` para apresentar as informações do agendamento (nome do cliente, serviço, duração, data e horário formatados, nome e endereço do estabelecimento). Criar a suíte de testes automatizados garantindo renderização de texto e HTML corretos.

## Context & Architecture

Na Phase 4 foi construída a infraestrutura de e-mail transacional via Resend (`enviarEmail`, `LayoutBase.tsx`, `montarRemetente`). Na Phase 5, quando um cliente final realiza um agendamento fornecendo e-mail, ele deve receber uma mensagem de confirmação (EML-03) identificada pelo estabelecimento (EML-04).

## Proposed Changes

### 1. React Email Template
#### [NEW] [ConfirmacaoAgendamento.tsx](file:///home/marcilio/Files/VamoAgendar/vamo-agendar-app/src/emails/ConfirmacaoAgendamento.tsx)

- Criar o componente React Email `ConfirmacaoAgendamento`:
  ```tsx
  interface ConfirmacaoAgendamentoProps {
      nomeCliente: string
      nomeEstabelecimento: string
      nomeServico: string
      duracaoServicoMinutos: number
      dataHoraFormatada: string // Ex: "Segunda-feira, 12 de Agosto às 14:30"
      endereco?: string | null
      instagram?: string | null
      linkBooking?: string
  }
  ```
- Estrutura interna:
  - Envolvido em `<LayoutBase titulo="Agendamento Confirmado" nomeEstabelecimento={nomeEstabelecimento}>`.
  - Cabeçalho: `"Olá, {nomeCliente}! Seu agendamento foi confirmado com sucesso."`
  - Card estilizado com os detalhes da reserva:
    - **Serviço**: `{nomeServico}` (`{duracaoServicoMinutos} min`)
    - **Data e Horário**: `{dataHoraFormatada}`
    - **Local / Estabelecimento**: `{nomeEstabelecimento}`
    - **Endereço**: `{endereco}` (se fornecido)
  - Botão de ação (CTA): `"Ver Agendamento"` apontando para o link da página pública ou agendamento.
  - Rodapé com nota amigável e link do Instagram (se fornecido).

### 2. Automated Tests
#### [NEW] [ConfirmacaoAgendamento.test.tsx](file:///home/marcilio/Files/VamoAgendar/vamo-agendar-app/src/emails/__tests__/ConfirmacaoAgendamento.test.tsx)

- Criar testes com Vitest utilizando `render` do React Email ou `@react-email/render`:
  1. Renderização HTML: verificar presença das strings do cliente, serviço, data/hora formatada e estabelecimento.
  2. Renderização Plain Text: verificar que o resumo em texto puro contém todas as informações essenciais.

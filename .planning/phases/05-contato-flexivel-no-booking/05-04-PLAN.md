# Plan 05-04 — Orquestração Multicanal e Desacoplamento Assíncrono com after()

## Objective
Orquestrar o disparo de notificações de confirmação de agendamento por WhatsApp, E-mail ou ambos (se ambos forem fornecidos), envolvendo o transporte em `after()` do Next.js para garantir a liberação instantânea da tela de sucesso na UI do cliente final.

## Proposed Changes

### Server Action & Notificações
#### [MODIFY] [public-booking.ts](file:///home/marcilio/Files/VamoAgendar/vamo-agendar-app/src/app/actions/public-booking.ts)
- Adicionar validação no servidor que exige Nome e pelo menos um entre WhatsApp e E-mail.
- Envolver os envios de notificação (E-mail via Resend, WhatsApp via Evolution API e QStash) em `after(async () => { ... })`.
- Retornar `{ ok: true, agendamentoId }` imediatamente após a transação no banco.

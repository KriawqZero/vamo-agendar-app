# Plan 05-04 — Orquestração Multicanal e Desacoplamento Assíncrono via `after()`

## Objective

Orquestrar o disparo de notificações de confirmação de agendamento por WhatsApp, E-mail ou ambos (conforme os canais fornecidos pelo cliente). Desacoplar o processamento de notificações e enfileiramento no QStash do request síncrono utilizando `after()` do Next.js, garantindo liberação instantânea da tela de sucesso na UI (~50-100ms) e resiliência absoluta do agendamento gravado no banco de dados.

## Context & Architecture

Conforme a pesquisa em `05-RESEARCH.md` e decisões em `05-CONTEXT.md`:
- **Success Criteria 3 (BOO-02)**: A UI deve avançar para a tela de sucesso assim que os registros no banco forem salvos.
- **Multicanal (BOO-03, EML-03)**:
  - Só WhatsApp: mensagem via Evolution API + agendamento de lembrete via QStash.
  - Só E-mail: mensagem via `enviarEmail` utilizando o template `ConfirmacaoAgendamento`.
  - Ambos: ambos os disparos são executados.
- Erros no envio externo são tratados via observabilidade (`reportarFalhaSilenciosaAguardando`) e jamais interrompem a confirmação do cliente final.

### 2. Server Action Pública & `after()`
#### [MODIFY] [public-booking.ts](file:///home/marcilio/Files/VamoAgendar/vamo-agendar-app/src/app/actions/public-booking.ts)

- Atualizar os parâmetros de `criarAgendamentoPublico`:
  - `clienteTelefone?: string`
  - `clienteEmail?: string`
- Validação de entrada:
  - Exigir `clienteNome`.
  - Exigir que pelo menos um dos dois (`clienteTelefone` limpo OU `clienteEmail` limpo) esteja presente. Se ambos forem nulos/vazios, retornar `{ ok: false, motivo: 'campos_obrigatorios' }`.
  - Se `clienteTelefone` for informado, validar dígitos numéricos (`10` ou `11`). Retornar `telefone_invalido` se incorreto.
  - Se `clienteEmail` for informado, validar formato e tamanho. Retornar `email_invalido` se incorreto.
- Envolver a chamada de notificação em `after()`:
  ```ts
  import { after } from 'next/server'

  // Grava cliente e agendamento no banco de dados
  // ...

  after(async () => {
      try {
          await dispararNotificacoesAgendamento(admin, {
              agendamentoId: agendamento.id,
              tenantId,
              clienteNome: nomeLimpo,
              clienteTelefone: telefoneLimpo || null,
              clienteEmail: emailLimpo || null,
              dataHora,
              timezone,
          })
      } catch (err) {
          reportarFalhaSilenciosaAguardando(err, 'booking:notificacao_assincrona_falhou')
      }
  })

  return { ok: true, agendamento }
  ```
